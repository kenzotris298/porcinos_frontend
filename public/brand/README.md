# Recursos de marca

Los archivos SVG actuales son una identidad visual inicial de la plataforma, no el logotipo oficial de una entidad.

- `logo.svg`: logotipo horizontal para encabezados o documentos.
- `logo-mark.svg`: símbolo cuadrado usado en el acceso y la navegación.
- `favicon.svg`: icono de la pestaña del navegador.

Para incorporar la marca oficial, reemplaza cada archivo conservando su nombre y formato. Entrega los logos en SVG (preferido) o PNG transparente; para `favicon.svg`, usa un símbolo cuadrado legible a 32 × 32 px. Si se autoriza el uso del logo ICA, proporciona el archivo vectorial aprobado y sus normas de color.
